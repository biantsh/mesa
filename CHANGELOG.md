# Changelog

## v0.1.1

- In the Index view, each folder in the grid now fills up to show its share of the supported files in the folder you're in, so the folders worth excluding stand out.

- Stopping or removing a folder that already has 500 or more files indexed now asks first.

- **Fixes:**
  - On macOS, the logo and title at the top of the window now line up with the window buttons.
  - A thin orange line no longer appears below the top of the window.
